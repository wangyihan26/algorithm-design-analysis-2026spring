## Homework 1 — Algorithm Design & Analysis

| # | Topic | Key Techniques |
|---|-------|----------------|
| 1 | Asymptotic Analysis | Master Theorem, recurrence solving |
| 2 | Divide & Conquer | Stooge-sort variant analysis, Merge Sort |
| 3 | Stock Profit Maximization | O(n) linear scan |
| 4 | Local Minimum Search | Binary search O(log n), full scan O(n) |
| 5 | Top-k Smallest Elements | Sorting, heap-based, external memory O(n log k) |
| 6 | Planet Collision Simulation | Stack-based simulation O(n) |
| 7 | 0/1 Knapsack | Dynamic programming O(nW) |
| 8 | Recover BST | Inorder traversal with violation detection |
| 9 | Trapping Rain Water | Two-pointer O(n), DP approach |
| 10 | Sum Root-to-Leaf Numbers | DFS tree traversal O(n) |

## Getting Started

### Prerequisites

- Python 3.10+ with Jupyter Notebook
- C++17 compatible compiler (GCC 9+ / Clang 10+ / MSVC 2019+)

### Running the Notebooks

```bash
git clone https://github.com/wangyihan26/algorithm-design-analysis-2026spring.git
cd algorithm-design-analysis-2026spring
jupyter notebook
```
